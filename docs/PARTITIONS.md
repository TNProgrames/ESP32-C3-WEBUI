# تقسيم الفلاش (4MB)

الجدول في `partitions.csv`. مساحة LittleFS (640KB) مقسّمة إلى ثلاث مساحات مستقلة، تُركَّب على `/c` و`/d` و`/e`، ويختار الموجّه `src/fs_router.h` المساحة من مسار الملف فلا يتغيّر بقية الكود.

| المنطقة | التسمية | العنوان | الحجم | المحتوى |
|---|---|---|---|---|
| nvs | `nvs` | `0x9000` | 20KB (`0x5000`) | إعدادات النظام |
| otadata | `otadata` | `0xE000` | 8KB (`0x2000`) | اختيار قسم OTA |
| app0 | `app0` | `0x10000` | 1664KB (`0x1A0000`) | الفيرموير |
| app1 | `app1` | `0x1B0000` | 1664KB (`0x1A0000`) | الفيرموير (OTA) |
| **C** | `fs_c` | `0x350000` | **128KB** (`0x20000`) | الواجهة: `/app/index.html.gz` |
| **D** | `fs_d` | `0x370000` | **64KB** (`0x10000`) | الإعدادات: `settings.json` `users.json` `wifi_nets.json` `em_key` |
| **E** | `fs_e` | `0x380000` | **448KB** (`0x70000`) | سكريبتات Lua (`/scripts`) والدرايفرات (`/drivers`) والتخزين (`/kv`) وإعدادات إقلاع التطبيقات (autorun) وصفحات التطبيقات (`/ui/*.html`) وأي ملف آخر |
| coredump | `coredump` | `0x3F0000` | 64KB (`0x10000`) | تفريغ الأعطال |

قاعدة التوجيه: `/app/*` ← C · الملفات الأربعة (وملفاتها `.tmp`/`.bak`) ← D · كل ما عدا ذلك ← E.

## فوائد التقسيم
- **تحديث الواجهة** (OTA `type=fs`) يستبدل C فقط؛ تبقى الإعدادات وكلمات المرور والسكريبتات والدرايفرات.
- مسح E (`/api/format?part=e`) لا يمسّ الإعدادات.
- ازدحام E لا يؤثر على الواجهة أو الإعدادات.

## ملفات CI والتفليش
يبني `tools/fs_images.py` ثلاث صور بأحجام `partitions.csv` ويكتب `flash.txt` (داخل `firmware-*.zip`):

```
0x350000  fs_c.bin  (128 KB, الواجهة)
0x370000  fs_d.bin  (64 KB، الإعدادات، فارغة)
0x380000  fs_e.bin  (448 KB، البيانات، فارغة)
```

تفليش كامل (أول مرة، أو بعد تغيير جدول الأقسام؛ التقسيم الجديد يمحو الملفات القديمة):
`esptool.py write_flash 0x0 bootloader.bin 0x8000 partitions.bin 0x10000 firmware.bin 0x350000 fs_c.bin 0x370000 fs_d.bin 0x380000 fs_e.bin`

تحديث الواجهة وحدها: `esptool.py write_flash 0x350000 fs_c.bin` أو من الواجهة برفع `fs_c-*.bin` (من ملفات الإصدار).

## مدير الطوارئ (/em)
- يعرض المساحات كأقراص ويندوز: الجذر فيه **C:** و**D:** و**E:** مع شريط استعمال والمساحة الحرة، والدخول إلى قرص يعرض مجلداته. المسارات داخل em بادئتها حرف القرص (`/c/app/...` و`/d/users.json` و`/e/scripts/...`)، وتُحذف البادئة قبل الوصول إلى المساحة.
- إنشاء ملف أو مجلد أو رفع ملف يتم في **القرص والمجلد المفتوحين**؛ وفي الجذر يُطلب فتح قرص أولًا.
- **التهيئة** تسأل أي قرص تُهيّئ: `C` أو `D` أو `E` أو `ALL` (الافتراضي القرص المفتوح)، عبر `/api/format?part=c|d|e` (وبدونه تُمسح الثلاث).
- زر **تحديث الواجهة (fs_c)** يرفع صورة `fs_c-*.bin` ويستبدل القرص C فقط؛ إن لم يحوِ اسم الملف `fs_c` يظهر تنبيه.
- `/api/list` يعيد `parts` (الحجم والمستعمل لكل مساحة) و`root:true` عند الجذر.
