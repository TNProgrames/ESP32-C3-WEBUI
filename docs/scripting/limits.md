# الحدود والأمان والأخطاء

> **✅ منفَّذ في v0.4** (الأرقام الفعلية): 3 سكريبتات، 8 مؤقتات، ذاكرة 48KB، استدعاء 200ms، نص السكريبت حتى 8KB، 6 قنوات PWM، 4 لوحات لكل سكريبت (6 إجمالًا)، 40 أداة إجمالًا. الأخطاء تظهر في الطرفية وعلى بطاقة السكريبت (بلا رقم سطر دائمًا). `@pins` و`@needs` والتعطيل الذاتي عند الانهيار **غير منفَّذة بعد**.

> الأرقام تقديرية وتُقاس على الجهاز عند التنفيذ.

## الحدود

| العنصر | الحد |
|---|---|
| سكريبتات تعمل معًا | 3 |
| حجم ملف السكريبت | 32KB |
| ذاكرة كل سكريبت | حوالي 48KB |
| مؤقتات لكل سكريبت | 8 |
| أدوات واجهة لكل سكريبت | 20 |
| علب لكل سكريبت | 4 |
| زمن الاستدعاء الواحد | 200ms (ثم يُقطع) |
| تخزين `storage` | 2KB لكل سكريبت |
| قنوات PWM | 6 على الجهاز كله |
| قنوات RMT | 2 إرسال + 2 استقبال على الجهاز كله |
| وحدات PCNT | 4 على الجهاز كله |
| نبضات لكل `rmt.send` | 512 |
| صفحات مخصصة لكل سكريبت | 2 (حتى 24KB) |

## الأرجل

| الرجل | الحالة |
|---|---|
| 0–4 | تناظرية صالحة (ADC1) |
| 2 و8 و9 | أرجل إقلاع (مع تحذير) |
| 18 و19 | محظورة (USB) |
| أرجل الفلاش | غير متاحة |

الرجل غير المعلنة في `--@pins` تسبب خطأ، فهكذا يُمنع تعارض السكريبتات ويُعرف ما يلمسه كل سكريبت قبل تشغيله.

## الأمان

- لا يعمل السكريبت إلا بصلاحية **admin**.
- بيئة معزولة: لا وصول لملفات النظام ولا `os` ولا `io`.
- حماية من الحلقات اللانهائية بمهلة لكل استدعاء.
- **تعطيل ذاتي:** إن انهار سكريبت الإقلاع أكثر من 3 مرات متتالية يُعطَّل تلقائيًا ويبقى الجهاز قابلاً للدخول.
- عند الإيقاف تُحرَّر الأرجل وتُعاد إلى وضع آمن (دخل).

## الأخطاء

تظهر في الطرفية وعلى بطاقة السكريبت بالأحمر مع رقم السطر:

```
[غرفة] line 12: attempt to call a nil value (field 'writee')
[غرفة] pin 5 not declared in @pins
[غرفة] pin 8 already owned by "إضاءة"
[غرفة] callback exceeded 200ms
```
