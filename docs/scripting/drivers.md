# الدرايفرات

> **✅ `require` منفَّذ (v0.7)**، و**🕒 الدرايفرات الجاهزة (SSD1306 وBME280...) قيد التنفيذ.**  يمكنك كتابة درايفرك بنفسك الآن فوق `i2c`.

## القاعدة

- **درايفر بـ Lua:** يكفيه `i2c` وما يشبهها. مناسب لـ OLED وBME280 وADS1115 وغيرها. يوضع في `/scripts/lib/` ويُحمَّل بـ `require`.
- **درايفر في الفيرموير (C++):** للبروتوكولات الحساسة للتوقيت (DHT وWS2812 والأشعة تحت الحمراء). تحميله يتطلب تحديث الفيرموير.

## الاستعمال

```lua
--@pins 6,7
--@needs i2c
local ssd1306 = require("lib/ssd1306")
i2c.begin(6, 7, 400000)

local oled = ssd1306.new(0x3C, 128, 64)
oled:clear()
oled:text(0, 0, "مرحبا ESP32")
oled:show()
```

## كتابة درايفر جديد (هيكل)

```lua
-- /scripts/lib/mydevice.lua
local M = {}
M.__index = M

function M.new(addr)
  local self = setmetatable({ addr = addr }, M)
  self:init()
  return self
end

function M:init()
  i2c.write_reg(self.addr, 0x00, 0x01)   -- تسلسل التهيئة حسب ورقة بيانات الجهاز
end

function M:read()
  local b = i2c.read_reg(self.addr, 0x10, 2)
  return (b[1] << 8) | b[2]
end

return M
```

## نصائح
- اقرأ ورقة بيانات الجهاز: عنوان I2C وتسلسل التهيئة ومعنى السجلات.
- استعمل `string.pack`/`string.unpack` لتحويل البايتات إلى أرقام.
- اجعل الدرايفر **بلا حالة عامة** وبلا حلقات انتظار.
- الشاشات: ارسم في ذاكرة وسيطة (framebuffer) ثم أرسلها كلها مرة واحدة في `show()`.
- لإضافة درايفر C++ جديد للفيرموير أخبرني وأضيفه ثم أجعله متاحًا للسكريبت.

## ✅ المطبّق فعليًا: `require` والمكتبات (v0.7)

- ملفات المكتبات في `/scripts/lib/<name>.lua`. من المختبر: فعّل **«حفظ كمكتبة (require) بدل التشغيل»** واكتب الاسم ثم **حفظ المكتبة**، وتظهر في قسم **📦 المكتبات** مع ✏️ وحذف.
- الاستعمال: `local m = require("name")` (أو `require("lib/name")`، وهما سواء). الاسم: حروف إنجليزية وأرقام و`_` و`-` حتى 23.
- تُحمَّل المكتبة **مرة واحدة** لكل سكريبت وتُخزَّن النتيجة. إن لم تعد المكتبة شيئًا تصير النتيجة `true`. حجم الملف حتى 8KB، ويُحسب كودها وذاكرتها من حصة السكريبت (48KB).
- يستقبل جسم المكتبة اسمها معاملًا (`...`). التداخل (مكتبة تطلب مكتبة) حتى 4 مستويات؛ وتُكتشف الدورات.
- الدالة `require` تعمل فقط على `/scripts/lib/`، ولا تقرأ أي ملف آخر.
- مكتبة `util` التجريبية في أمثلة المختبر: «Library: util (save as lib)» ثم «Use library: util».
