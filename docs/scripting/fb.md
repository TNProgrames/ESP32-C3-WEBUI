# fb — إطار الرسم (1 بت)

> **✅ منفَّذ في الفيرموير.** إطار نقاط داخل ذاكرة Lua (128×64 = 1KB) بصيغة صفحات SSD1306، يُرسَم بسرعة C++.

```lua
local f = fb.new(128, 64)     -- w 1..128، h 8..64 (مضاعف 8)
f:text(0, 0, "25.3\194\176C", 2)
f:bar(0, 40, 100, 8, 60)
```

| الدالة | الوصف |
|---|---|
| `fb.new(w, h)` | إطار جديد |
| `f:clear([c])` / `f:invert()` | مسح / عكس |
| `f:pixel(x,y[,c])` / `f:get(x,y)` | كتابة/قراءة نقطة |
| `f:line(x0,y0,x1,y1[,c])` | خط |
| `f:rect(x,y,w,h[,c[,fill]])` | مستطيل |
| `f:circle(cx,cy,r[,c[,fill]])` | دائرة |
| `f:bar(x,y,w,h,percent[,c])` | شريط تقدم |
| `f:text(x,y,str[,scale[,c]])` | نص 5×7 (scale 1..4، يدعم `\n`)، يعيد x بعد آخر حرف |
| `f:text_width(str[,scale])` | عرض النص |
| `f:page(p)` / `f:data()` | بايتات صفحة / كل الإطار (نص) |
| `f:size()` | `w, h` |

الألوان: `0` إطفاء، `1` إضاءة، `2` XOR (ويقبل `true/false`). الخط ASCII فقط مع `°` (`\194\176`)؛ بقية رموز UTF-8 تظهر `?`.
