# توثيق السكريبت (Lua) — مسودة التصميم

> **الحالة: مقترح قيد المراجعة.** هذه الواجهة (API) لم تُنفَّذ بعد في الفيرموير. الغرض الاتفاق على التصميم قبل الكتابة، وتعديلها سهل الآن.

السكريبت برنامج صغير بلغة **Lua** يعمل على الجهاز، يتحكم بأرجل ESP32-C3 ويقرأ الحساسات ويتحدث مع الشاشات، ويعرض أدوات (نصوص وأزرار وأشرطة) في **علب (panels)** داخل الواجهة.

## هيكل ملف السكريبت

```lua
--@name    غرفة المعيشة
--@version 1.0
--@pins    0,5,8          -- الأرجل التي سيستعملها (إلزامي لأي رجل تستعملها)
--@needs   i2c            -- الوحدات: gpio adc pwm i2c uart (اختياري)

local oled = require("lib/ssd1306")   -- درايفر مكتوب بـ Lua

-- 1) الإعداد: يُنفَّذ مرة واحدة عند التشغيل
gpio.mode(8, "out")
local box = ui.panel("غرفة المعيشة")

-- 2) الأحداث: مؤقتات وأزرار وتغيّر الدخل
timer.every(2000, function() ... end)

-- 3) التنظيف (اختياري): يُستدعى عند الإيقاف
function on_stop() gpio.write(8, 0) end
```

**القاعدة الذهبية:** لا حلقات لا نهائية ولا انتظار. كل شيء **أحداث** (مؤقتات وأزرار وتغيّر دخل). هذا يُبقي الجهاز والواجهة مستجيبين ويسمح بتشغيل عدة سكريبتات.

## دورة الحياة

1. **تحميل:** يُقرأ الملف وتُتحقق الترويسة (`@pins` و`@needs`) وتُحجز الأرجل.
2. **تشغيل:** يُنفَّذ الجسم مرة واحدة (الإعداد).
3. **أحداث:** تُستدعى الدوال المسجلة (مؤقت، زر، تغيّر رجل) كل في دورها.
4. **إيقاف:** يُستدعى `on_stop()` إن وُجد، ثم تُلغى المؤقتات وتُحذف العلب وتُحرَّر الأرجل.

## عدة سكريبتات

- كل سكريبت في بيئة Lua **مستقلة**: انهيار أحدها لا يوقف الباقي.
- كل رجل يحجزها سكريبت واحد (خطأ واضح عند التعارض).
- ناقل I2C مشترك ومنظَّم بقفل.
- للتبادل بين السكريبتات استعمل `bus` (انظر [system.md](system.md)).

## الطبقات: ما في الفيرموير وما في السكريبت

- **في الفيرموير (C++):** العمليات الأساسية (GPIO وADC وPWM وI2C وSPI وUART) وأدوات التوقيت الدقيق (RMT وPCNT والمقاطعات). السكريبت يصف والعتاد ينفّذ، فانظر [timing.md](timing.md). لا يمكن تحميل كود C++ أثناء التشغيل، فدرايفر جديد من هذا النوع يعني تحديث الفيرموير (OTA).
- **في السكريبت (Lua):** درايفرات أجهزة I2C/SPI البسيطة (OLED وBME280 وغيرها) فوق الدوال الأساسية. انظر [drivers.md](drivers.md).

## الإصدارات

اللغة: Lua 5.4. المكتبات القياسية المتاحة: `math` و`string` و`table` و`utf8` و`pcall`/`error`. غير متاحة لأسباب أمنية: `os` و`io` و`debug` و`dofile` و`loadfile`. و`require` لا يقرأ إلا من `/scripts/lib/`.
